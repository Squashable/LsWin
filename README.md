# LS commands for Windows
the point of this project was to help me with debugging windows machines, I'm a little familiar with some linux commands such as;
	
  `LSCPU LSPCI LSUSB 	LSCRASH LSDISK	LSMEM`

# How to interact with this CLI tool
The command options are :
#### lscpu, lspci, lsusb, lscrash, lsdisk, lsmem

For the options that can print out a list, two options will appear, 
`[1] more details`
`[2] back to menu`
option one prints out the refined search term and if you select the next set of options it will print it out in a more human readable fashion.
